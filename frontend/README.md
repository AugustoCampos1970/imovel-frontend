# 🏠 Imóvel - Frontend

Interface web do sistema de gestão de imóveis.

## 🛠️ Tecnologias

- React
- Vite
- Tailwind CSS

## 🚀 Como rodar localmente

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev
```

## 📁 Estrutura

```
frontend/
├── src/          # Código fonte
├── index.html    # Entrada principal
└── vite.config.js
```
